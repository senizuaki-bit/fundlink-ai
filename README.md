# FundLink AI

公开演示源码仓库，面向 AI 辅助的双边投融资信息匹配与证据分析。仓库不包含真实账户、私有上传材料、运行数据库或 API 密钥。

根据 FundLink AI PRD V1.0 持续完善的本地 MVP：中文双边投融资网站。完整产品愿景尚未全部实现，见逐项清单及剩余边界。首页选择「我要投资 / 我要融资」，账户与两个身份的工作记录和材料隔离保存。

完整模块、实现位置和验收方法见 [逐项验收清单](docs/PRD_IMPLEMENTATION.md)，原始需求见 [PRD](docs/FundLink_AI_PRD_V1.0.md)。

## 本地启动

安装 Node.js 24 LTS。在项目目录打开终端：

```powershell
git clone https://github.com/senizuaki-bit/fundlink-ai.git
cd fundlink-ai
npm ci
npm run db:init
npm run dev
```

然后访问 http://127.0.0.1:5173 。Windows 也可双击「启动网站.cmd」。首次初始化会构建运行配置、创建本地数据库；再次运行会保留已有资料。不要删除 `.wrangler/state`，它包含本地数据库和上传文件。

本地开发登录由 starter 提供，适合本人演示；正式多用户网站需平台认证、独立部署与成员授权。不要直接把开发服务开放到公网；发布源码不等于已提供可公开注册的在线服务。

## 模型与搜索配置

将 `.env.example` 复制为 `.env.local`，填写 `DEEPSEEK_API_KEY`，然后重启开发服务。默认模型 `deepseek-flash`。也可配置 OpenAI；两者同时配置时优先 DeepSeek。`BRAVE_SEARCH_API_KEY` 是新闻搜索的可选服务端密钥；没有时可直接导入官方公告链接。

密钥仅在服务端使用，不打入浏览器、不加入源码包。不配置模型仍可使用规则模式，界面会明确显示模式。模型研究会使用当前输入、画像和所选授权证据；可在 Agent 设置关闭知识库读取或其他工具。

## 可以操作的完整链路

- 双身份十维建档、模型抽取与人工确认、浏览器语音（支持时）、渐进式画像和字段历史。
- 真实公开项目/模型/论文检索，基金官网/公告导入，结构化证据库、主体关联、私有 BP 提取与跨源核查。
- 双端共用的服务端推荐：硬条件、双向独立适配、全文与概念检索、不同候选换批、证据质量和风险解释。
- DeepSeek Agent 执行检索、证据查询、比对、计算、匹配、草稿与交易跟进工具，展示执行过程和来源。
- 带服务端阶段校验的模拟交易工作台、意向确认、材料权限、草稿审批、会议和尽调记录。
- 六类资本诊断、资金计划、股权与期权池情景、基础财务公式、双方尽调框架。
- 平台统一事件与反馈回流，默认关闭的行为学习及明确授权、撤回、清除；同主体联合研究；全部公开来源分页巡检和本地后台定时检查。

## 真实与模拟

公开 API、数据库、私有文件、证据比较、公式计算和模型调用是实际功能。内置企业/基金为明确标注的虚构案例；匹配分数不是成交概率。邮件发送、对手意向、分享范围是演示记录；没有替外部主体确认、对外发送资料、签约或划款。未认领线索的身份、融资意愿与当前资金能力保持待核实。完整限制见验收清单。

## 2026-10-10 升级

新增双方专业画像、四类字段来源及人工核验、多轮 Agent、行为学习主动授权、同主体证据联合研究、多来源巡检与本地后台调度。详见 [本轮完善说明](docs/UPGRADE_2026-10-10.md)。

旧版本升级请先运行 `npm run db:init`（保留原有数据），再运行 `npm run dev`。后台巡检在「机会监测 / 关注资本」选择真实主体后主动启用。网站进程运行期间可关闭浏览器；停止进程或电脑休眠就会暂停执行。旧版默认开启的行为学习会按未授权处理，需在「我的画像」明确开启。

## 平台反馈架构

数据飞轮已经移到双端共用的后台架构：投资和融资的业务动作进入统一事件层，由共用推荐服务在权限范围内消费反馈。两端侧边栏不再单列「数据飞轮」，授权与偏好在画像管理，实际业务反馈在交易工作台，证据复核在知识库。

统一事件保留企业—投资机构的固定方向、来源与授权状态；账户和角色的私有数据仍然隔离。当前采用规则学习，未认领主体不会自动形成跨账户交易对，单侧登记也不代表对方确认。详见 [平台架构](docs/PLATFORM_ARCHITECTURE.md) 与 [反馈机制和指标口径](docs/DATA_FLYWHEEL.md)。
