# FundLink AI｜产品方案简版

用 AI 连接寻找项目的投资方和寻找资金的企业，让双方完成发现、分析、匹配与跟进，并通过反馈持续改善推荐。

[GitHub 公开仓库](https://github.com/senizuaki-bit/fundlink-ai) · [详细设计与实现说明](https://github.com/senizuaki-bit/fundlink-ai/blob/main/docs/PRODUCT_DESIGN.md)

## 1 为什么做

投资方难以从分散信息中找到合适项目，企业也难以判断哪些资金真正适合自己。搜索能找到资料，FundLink 进一步把资料归到同一主体、交叉核查，再解释双方为什么适配、还缺什么信息。

## 2 用户怎么用

首页选择“我要投资”或“我要融资”。通过约十个维度的文字、选项或语音问答建立基础画像，允许选择“不确定”，后续逐步补全。

| 功能 | 投资侧 | 融资侧 |
|---|---|---|
| 建立画像 | 投资方向、阶段、金额与限制 | 公司情况、融资用途、金额与资源需求 |
| 发现机会 | 项目雷达，挖掘 GitHub、官网等线索 | 资本雷达，研究基金、机构与投资案例 |
| 研究分析 | 核查项目资料、商业进展和风险 | 核查基金偏好、资金条件和合作风险 |
| 推荐与跟进 | 换一批、收藏、筛选、记录尽调 | 换一批、筛选资本、准备材料、记录进展 |

双方都拥有可配置的个人 Agent，可以用对话发起检索、比较对象、计算融资情景、整理问题和材料；涉及对外行动时需要明确授权。

## 3 AI 怎么工作

**采集 → 建档 → 核查 → 匹配 → 解释。**

从公开平台或授权材料中提取信息，保存来源和时间，形成企业与资本画像。跨源分析先核对主体、时间及指标口径；数据不一致时提示差异和待核实问题，不直接判定造假。

匹配先检查阶段、金额、地域等硬条件，再分别计算“投资方是否适合投”和“企业是否适合接受”。结果展示理由、证据、缺口与下一步；匹配分不是成交概率，也不代表对方已经愿意合作。

## 4 数据飞轮放在哪里

**数据飞轮是双端共用的架构机制。** 用户在正常研究和跟进中产生收藏、拒绝、证据纠正及业务反馈，平台按授权记录，改善下一轮画像、核查与推荐。

私有材料保留原有权限；行为学习由用户开启，偏好变化需要确认。模拟反馈与真实业务分开，不能把单侧自报当成双方确认。

![双端数据飞轮](assets/fundlink-shared-flywheel.svg)

## 5 系统怎么组织

投资端和融资端共用证据、匹配、Agent 与业务服务，统一事件层连接各模块。当前采用 React / TypeScript、D1 / R2 和可配置模型接口；模型负责理解与解释，程序负责权限、计算和状态一致性。

![系统架构](assets/fundlink-platform-architecture.svg)

## 6 现在做到哪一步

**已有本地 Demo：** 双端建档、公开线索检索、证据入库、基础跨源核查、双向匹配、工具型 Agent，以及经授权的事件反馈。

**还需完善：** 定时发现全新线索、真实跨账户协作、双方独立确认和基于真实样本的效果验证。已有来源的本地巡检不等于持续发现新项目。

**体验方式：** 按 GitHub README 在本地启动。下一步先打通持续发现与真实双边协作，再验证是否减少研究时间、提高有效沟通。
