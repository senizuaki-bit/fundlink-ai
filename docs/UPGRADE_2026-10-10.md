# FundLink 本轮完善记录 · 2026-10-10

本轮补齐了已识别的画像、授权、上下文、关联证据和本地巡检缺口。当前仍是有真实数据处理能力的本地 MVP，不把下方剩余工作算作已完成。

## 已增加或修正

1. **双方专业画像**：融资方增加 19 项，涵盖主体、团队、产品、经营、财务、历史融资、股权、估值、资金用途和 BP；投资方增加 17 项，涵盖基金、代表授权、正式策略、个人研究兴趣、历史项目、资源、冲突和决策流程。可分组编辑、保存并查看变更历史。
2. **四种来源属性**：明确声明、自述、AI 推断、人工核验分别保存。修复保存时覆盖推断属性的问题。人工核验必须绑定当前字段值、来源网址或当前身份的上传文件、核对说明和主动确认；修改内容后旧核验失效。人工核验表示用户核对记录，不等于平台独立认证。
3. **行为学习授权**：默认关闭，旧版仅有 `learning=true` 不视为同意。服务端记录明确授权时间，只有本次授权后的新信号可用于排序；历史收藏不会偷偷追溯使用。可撤回及清除行为记录，保留收藏、业务记录和已确认偏好。行为学习不能突破硬条件。
4. **Agent 多轮上下文**：仅使用服务端当前账户、身份、所选对象的历史，最多 12 条、12,000 字；可单轮关闭。历史输出不作为事实或行动授权。财务追问只继承用户明确输入，支持新值覆盖，不混用币种与期间；权限收紧后保守排除历史。
5. **同主体联合研究**：仅经人工确认“同一主体”的关联可以联合检索、比较主张。持有、投资、维护等关系不当作同一主体。来源和主张保留原始归属；撤回关联或删除证据后重算。相同完整公开网址可产生待核验建议，不自动认定身份。
6. **多来源监测**：覆盖选定主体的全部公开网址，去重版本并分页继续；记录前后来源、变化片段、主题和失败。手动每页最多 12 个网址，后台每页最多 6 个。
7. **本地后台巡检**：在“机会监测 / 关注资本”主动选择 1–6 个真实主体，设置每 1、6、12 或 24 小时运行。`npm run dev` 的 Node 服务执行后台心跳，浏览器关闭后仍可运行。租约避免重复执行，修改或暂停计划不会被旧任务覆盖；失败计数、退避和分页进度均保留。

## 使用和升级

```powershell
npm run db:init
npm run dev
```

数据库升级只创建新表，保留已有画像、资料与交易记录；也可以双击“启动网站.cmd”。旧版行为学习需要在“反馈与学习”重新明确开启。

后台任务依赖本机网站进程；电脑休眠、关机或停止服务期间不会执行，恢复后补检到期计划。界面显示心跳与最近结果。没有后台云服务时不要把本地心跳当成全天在线。任务不发送邮件、系统通知或私有文件。

- 浏览器核对双方专业字段、来源核验禁用条件、默认未授权及授权弹窗、Agent 历史开关；本地后台心跳已实际运行。没有代用户开启学习或配置真实周期任务。

## 仍未完整实现

- 对外邮件、真实对方意向确认、跨账户 Deal Room 与资料共享仍为模拟；组织成员、机构级权限和独立身份核验未接通。
- 新闻搜索需要 Brave 密钥；商业金融数据库与机构业务系统未接入。
- 专业详情是结构化分组文本，正式授权详情不会自动解析成基础匹配硬条件；发生冲突时需要同步核对基础画像。
- 匹配采用规则、分词与人工概念词典，不是训练得到的向量或排序模型。实体关联仍需人工确认。
- 风险卡以可解释的规则及证据分析为主，未形成通用的市场、法律、IP 与复杂条款自动审查系统。
- 自动分析支持文本 PDF/TXT/Markdown/CSV/JSON；扫描件 OCR、PPTX/DOCX/XLSX 解析尚未加入。
- 后台仅实现本地运行方式；独立云端 Cron、主动消息通知、真实签约交割与资金操作未接入。

完整 PRD 的愿景仍需后续迭代；本轮完成范围以上述实际功能和测试为准。
